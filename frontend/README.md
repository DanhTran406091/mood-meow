# Frontend Mood & Meow

Xem [README đầy đủ của đồ án](../README.md) để cài công cụ, requirements, npm, chạy hai chế độ, thu mẫu, train/test và xử lý lỗi.

Chạy tại thư mục frontend sau khi cài công cụ; cần backend chạy đồng thời:

~~~powershell
npm.cmd ci
npm.cmd run dev
~~~

Kiểm tra khi sửa code:

~~~powershell
npm.cmd run build
npm.cmd run lint
npm.cmd run test:gestures
~~~
